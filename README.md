# English RU — английский для русскоязычных (A1–B1)

Веб-приложение для изучения английского: словарь, интервальные повторения (SRS), уроки, аудирование и прогресс. Интерфейс на русском, контент — английский с переводами.

## Возможности

- **Главная** — серия дней (streak), цель на сегодня, урок дня
- **Словарь** — ~108 слов с EN / RU / примером и кнопкой озвучки (Web Speech API)
- **Карточки SRS** — Again / Hard / Good / Easy, прогресс в `localStorage`
- **Уроки** — 5 тематических уроков (грамматика + лексика) с упражнениями
- **Аудирование** — `speechSynthesis` → выбор перевода
- **Прогресс** — выученные слова, точность, серия
- **Настройки** — дневная цель, сброс прогресса

Без авторизации и без платных API. Всё работает в браузере на этом устройстве.

## Стек

- Next.js (App Router)
- TypeScript
- Tailwind CSS

## Запуск

```bash
cd /workspace/english-app
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

### Сборка

```bash
npm run build
npm start
```

## Структура данных

- `src/data/words.ts` — словарь
- `src/data/lessons.ts` — уроки
- Прогресс: ключ `english-app-progress-v1` в `localStorage`

## Уроки

1. Приветствия и знакомство (A1)
2. Семья и люди (A1)
3. Еда и напитки (A1)
4. Present Simple и распорядок дня (A2)
5. В городе и путешествия (A2)

## Примечание

Озвучка зависит от голосов браузера (`speechSynthesis`). В некоторых окружениях голоса могут быть недоступны — кнопки всё равно работают, если API поддерживается.
